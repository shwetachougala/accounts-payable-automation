# Accounts Payable Automation

This is a project, developed to make the accounts payable process easier.
It uses React for the frontend, Django REST Framework for the backend, and PostgreSQL for storing data.

The application allows users to manage vendors, upload invoices, extract invoice details using OCR, validate invoices, manage approvals, track payments, and generate reports.

**Technologies Used:** React, Python, Django REST Framework, PostgreSQL, Tesseract OCR.

**To Run:**
Set up the PostgreSQL database
configure the backend `.env` file
install the required dependencies
run Django migrations and start both the backend and frontend servers.

**Note:**
The OCR feature uses basic text extraction and may require manual corrections. This project is developed for learning and demonstration purposes.
